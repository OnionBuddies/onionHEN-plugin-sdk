# Support

This repository supports development of the OnionHEN Plugin SDK. It does not
provide support for console exploits, firmware jailbreaks, piracy, PSN access,
or unrelated payloads.

Before asking for help:

1. Read [README.md](README.md) and [docs/architecture.md](docs/architecture.md).
2. Search existing issues.
3. Reproduce with the latest default branch.
4. Run the host tests and include their output.

Use the bug report form for reproducible SDK failures and the feature request
form for API proposals. General questions may use GitHub Discussions if it is
enabled for the repository. Never post private keys, credentials, proprietary
SDK files, decrypted system binaries, or personally identifying console data.
